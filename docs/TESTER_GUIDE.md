# BT Android Agent — 試用說明

> Tymphany SQA · 藍牙喇叭驗證工具
> 版本 **v0.00.10**（debug）· 系統需求 **Android 12 以上** · 需要一支藍牙喇叭／耳機

一支跑在 Android 手機上的藍牙喇叭驗證 App，涵蓋連線壓測、音訊延遲、聲道、音量線性、HFP 通話切換等量測，所有結果自動存成 CSV。這份是給試用同仁的快速上手說明。

---

## 1. 安裝與授權

1. 把拿到的 `BT_Android_Agent2-debug.apk` 複製到 Android 手機，點開安裝。第一次會跳「**允許安裝未知來源的應用程式**」，打開該來源的權限即可。
2. 第一次開啟時，請**全部允許**以下權限，否則對應的測試會無法執行：
   - 藍牙（掃描 / 連線）
   - 位置（藍牙掃描需要）
   - 麥克風
   - 通知

> 先在手機的系統藍牙設定裡，把要測的喇叭**配對好**，再進 App 操作最順。

---

## 2. 基本操作流程

1. 開 App 後，左上角滑出**側邊選單**可切換各個測試頁面。
2. 先到 **Dashboard** 掃描／選取你的喇叭，按 `Connect` 連上。
3. 切到想測的頁面，按該頁的 **Start** 開始，看畫面上的即時數據與 log。
4. 測完按 **Stop**；結果會自動寫進 CSV（見第 4 段）。

> 測試進行中若切換頁面，App 會先問你要不要停止目前的測試，避免誤中斷。

---

## 3. 各測試頁面在做什麼

| 頁面 | 功能 | 怎麼用 / 注意 |
|------|------|--------------|
| **Dashboard**（總覽） | 掃描、配對、連線／斷線、播放測試音、查看 codec 與連線狀態 | 這裡是起點 |
| **Stress Test**（連線壓測） | 自動重複「播放→斷線→重連」迴圈 | 統計連線時間的 **平均 / 成功率 / P90 / P95 / 回復時間** |
| **Media Control**（AVRCP） | 測上一首／下一首／播放暫停／音量等媒體鍵，含快速壓測與回應時間 | **需背景開著音樂播放器（如 Spotify）** |
| **HFP / SCO**（通話切換） | 手動或自動在 A2DP（音樂）↔ HFP（通話）之間切換 | 量測 SCO 切換延遲 |
| **Stability Monitor**（長時監控） | 背景服務長時記錄電量、RSSI 訊號、音訊路徑、斷音事件與 RF 品質分數 | 適合長時間穩定度觀察 |
| **Acoustic**（聲道 loopback） | 喇叭放左右不同頻率、用手機麥克風收音判斷。支援 Normal／Swap／單聲道 | 一鍵 **Auto Diag** 自動判 PASS/FAIL |
| **Audio Latency**（延遲） | 量測音訊端到端延遲 | 跑 5 輪取**平均、抖動（jitter）與 P95** |
| **Audio Clock Drift**（時脈偏移） | 用 1kHz 參考音量測手機與喇叭之間的**時脈偏移（ppm）** | 含環境 SNR 監控 |
| **Volume Linearity**（音量線性） | 自動掃 0–15 共 16 級音量 | 檢查增益是否線性、有沒有「無效級距」 |
| **Log Explorer**（記錄管理） | 在 App 內瀏覽、預覽、分享所有 CSV 記錄檔 | 不用接電腦 |

> **量測小提醒：** 聲學類測試（Acoustic／Latency／Clock Drift／Volume）靠麥克風收音，請在**安靜環境**、把喇叭音量開足、手機離喇叭近一點，結果才準。

---

## 4. 測試記錄存在哪裡

所有 KPI 與測試結果會自動存成 CSV，放在手機的下載資料夾：

```
Downloads/BT_Android_Agent_Logs/
```

- **App 內看：** 直接到 **Log Explorer** 頁面，點檔案可快速預覽、也能分享出來。
- **每次啟動**會有一個 session ID，串起同一輪測試的各個 log，方便對照。
- 主要檔案：`TestSummary_日期.csv`（總表）、`AcousticDiag_日期.csv`、`StabilityLog_日期.csv` 等。

---

## 5. 已知限制（遇到請別當成 bug）

- 連線／斷線是**盡力而為**，部分動作受 Android 版本與手機廠牌限制，行為可能不同。
- **Media Control** 的媒體鍵若沒開背景播放器，按了會像沒反應，屬正常。
- 喇叭**電量**不是每支都會回報給第三方 App。
- **HFP/SCO** 切換行為各家手機差異大，可能受 OEM 音訊路由政策影響。
- 這是 **debug 版**（未簽章），僅供內部試用。
